# Preliminary map figures

These figures summarize exploratory visual checks from the NISAR L-band and S-band GCOV data for the Bihar study area. The HH low-backscatter and adaptive score layers are candidate evidence only; they are not validated water masks. Areas shown are threshold-dependent screening estimates.

The current work uses one acquisition date, so it does not provide a time-series change-detection result. The figures are image exports for review and are not georeferenced GIS deliverables. See the report and notebook in the repository for methods and context.
